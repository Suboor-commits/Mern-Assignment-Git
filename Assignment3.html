Practice Exercise Complete the following tasks using terminal commands: 1. Create a `website` folder containing `index.html`, `css/style.css`, and an `images` folder. 2. Enter the `css` folder and return to `website` using `cd ..`. 3. List all files and folders recursively using `ls -R`. 4. Rename `index.html` to `home.html`, then rename it back. 5. Open the project folder in VS Code. ## 3. Answers – Commands Used The following commands are for Windows PowerShell. **Step 1: Go to the home directory** ```powershell cd ~ ``` **Step 2: Create the website folders** ```powershell mkdir website mkdir website/css mkdir website/images ``` **Step 3: Create the required files** ```powershell New-Item website/index.html -ItemType File New-Item website/css/style.css -ItemType File ``` **Step 4: Enter the CSS folder** ```powershell cd website/css ``` **Step 5: Return to the website folder** ```powershell cd .. ``` **Step 6: List all files and folders recursively** ```powershell Get-ChildItem -Recurse ``` **Step 7: Rename the HTML file** ```powershell Rename-Item index.html home.html ``` **Step 8: Rename it back** ```powershell Rename-Item home.html index.html ``` **
