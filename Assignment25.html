Design Choices

Colour: Deep blue communicates professionalism, while orange highlights important actions.

Typography: The system font stack loads quickly, and a line-height of 1.6 improves readability.

Layout: The content is limited to 850px on larger screens, with white cards against a light background.

Responsive Design: Media queries adjust navigation, spacing, and tables for smaller screens.

Accessibility: Form labels, visible focus indicators, semantic table headings, and reduced-motion support improve usability.

Maintainability: CSS custom properties keep the main theme colours and border radius in one place.
