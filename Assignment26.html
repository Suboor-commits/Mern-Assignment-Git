1. Understanding the Box Model

Every HTML element is represented as a rectangular box. The CSS Box Model consists of four layers: content, padding, border, and margin.

2. Box Model Calculation

The original .my-box uses box-sizing: content-box. Its declared width and height apply to the content only.

Measurement Calculation Result
Content width 200px 200px
Total width without margin 200 + (20 × 2) + (10 × 2) 260px
Total width including margins 260 + (30 × 2) 320px
Content height 80px 80px
Total height without margin 80 + (20 × 2) + (10 × 2) 140px
Total height including margins 140 + (30 × 2) 200px

3. The border-box Model

With box-sizing: border-box, the declared width and height include both padding and border. If the width is 200px, padding is 20px on each side, and the border is 10px on each side, the content width becomes:

Content width: 200 − (20 × 2) − (10 × 2) = 140px

The total width including margins would be 200 + (30 × 2) = 260px.

Developers commonly use * { box-sizing: border-box; } to make element sizing easier to manage. In this demonstration, the universal rule is overridden for .my-box so the original content-box calculation remains accurate.

4. How to Inspect the Box Model

  1. Open this page in your browser.
  2. Press F12 to open Developer Tools.
  3. Select the Elements panel.
  4. Click the element with the class my-box.
  5. Open the Computed panel to inspect its dimensions.
