CSS Selector Summary

  • * — Universal selector
  • p — Element selector
  • .card — Class selector
  • #special — ID selector
  • h2, h3 — Grouping selector
  • .card a — Descendant selector
  • ul > li — Child selector
  • h2 + p — Adjacent sibling selector
  • [target="_blank"] — Attribute selector
  • :hover and :focus — Pseudo-classes
  • ::first-line — Pseudo-element
