# Assignment 2 – Setup Proof (VS Code, Node.js, and Live Server) ## Objective The objective of this assignment is to install and verify VS Code, Node.js, and Live Server and take a screenshot as proof that everything is working correctly. ## Steps ### 1. Check VS Code - Open Visual Studio Code. - Click **Help → About**. - Note down the VS Code version. ### 2. Check Node.js and npm - Open the VS Code terminal by pressing **Ctrl + `**. - Run the following commands one by one: ```bash node -v npm -v ``` - Note down the versions displayed in the terminal. ### 3. Install and Run Live Server - Open the Extensions panel by pressing **Ctrl + Shift + X**. - Search for **Live Server by Ritwick Dey**. - Click **Install**. - Open any `.html` file in VS Code. - Right-click and select **Open with Live Server**, or click **Go Live** in the status bar. - Your HTML file will open in the browser, usually at `http://127.0.0.1:5500`. ### 4. Take a Screenshot - Arrange your windows so that the following are visible: - VS Code - Terminal showing the Node.js version - Live Server extension - Browser displaying your HTML page - Take a screenshot of your screen. - Save the screenshot as `setup-proof.png` inside a folder named `screenshots`. ### My Setup Proof Add your own screenshot below after completing the setup. ![Setup
