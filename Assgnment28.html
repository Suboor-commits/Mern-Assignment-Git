Fixing CSS Overflow Problems

Learning how to prevent images, text, tables, and code from breaking a webpage layout.

FIX 1 & 2

1. Responsive Image

The image uses max-width: 100% and height: auto to fit its container without stretching beyond its natural proportions.

The image adjusts to the available width of the card.

Why it works: max-width: 100% prevents the image from exceeding its parent container.
FIX 3

2. Long Unbroken Text

This URL is intentionally long and has no spaces: https://www.example.com/this/is/a/very/long/url/that/would/normally/stretch/the/layout/sideways/forever/and/ever

Why it works: overflow-wrap: anywhere lets long URLs and unbroken words wrap when needed.
FIX 4

3. Wide Table

On small screens, scroll horizontally inside the table container instead of making the whole page wider.

ID Name Email City Course Year
1 Abdul Suboor Khan student@example.com Meerut BCA First Year

Note: The email shown is a placeholder example.

Why it works: overflow-x: auto makes the table's container scroll when the table is wider than the available space.
FIX 5

4. Fixed-Height Box

The following box has a fixed height. Scroll inside it to read all the text.

Lorem ipsum dolor sit amet, consectetur adipiscing elit. Sed do eiusmod tempor incididunt ut labore et dolore magna aliqua. Ut enim ad minim veniam, quis nostrud exercitation ullamco laboris nisi ut aliquip ex ea commodo consequat. Duis aute irure dolor in reprehenderit in voluptate velit esse cillum dolore eu fugiat nulla pariatur. Excepteur sint occaecat cupidatat non proident, sunt in culpa qui officia deserunt mollit anim id est laborum.
Why it works: overflow-y: auto adds a vertical scrollbar only when the content needs more space than the box provides.
FIX 6

5. Long Code Block

Code often contains long lines that should remain intact. Horizontal scrolling keeps them from widening the page. 

const message = "This line is intentionally very long so that it would overflow the container if not for overflow-x: auto";
Why it works: overflow-x: auto keeps long code lines inside the code block and lets users scroll horizontally.

Summary: CSS Overflow Fixes

  • box-sizing: border-box includes padding and border in declared dimensions.
  • max-width: 100% keeps images within their containers.
  • overflow-wrap: anywhere wraps long URLs and words.
  • overflow-x: auto handles wide tables and code blocks.
  • overflow-y: auto makes overflowing fixed-height content scrollable.
  • Responsive widths help prevent horizontal page overflow on mobile devices.
